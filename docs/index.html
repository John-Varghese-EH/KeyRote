How It Works

1

Intercept Request

Your client sends a standard LLM payload to KeyRote instead of the direct provider API.

2

Inject Healthy Key

KeyRote pulls the least-used healthy API key from Redis and injects it into the Authorization header.

3

Transparent Proxy

The request is forwarded exactly as-is. If a 429 occurs, KeyRote intercepts it, marks the key exhausted, and retries automatically.

4

Stream Response

The successful response (including SSE streams) is piped directly back to your client with zero noticeable latency.

1-Click Integration

Replace your provider's base URL with your KeyRote instance. No SDK changes required.

await fetch("https://proxy.your-domain.com/proxy", {
  method: "POST",
  headers: {
    "Authorization": "Bearer PROXY_SECRET",
  },
  body: JSON.stringify({
    target: "https://api.openai.com/v1/chat/completions",
    payload: { ...your_standard_payload }
  })
});
